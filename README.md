# Health Tracker

A personal daily health-habit tracker (phone-first web app, installable on Android).

- Plan and decisions: [PLAN.md](PLAN.md)
- Stack: React + Vite, Supabase (database + login), Vercel (hosting)

This repository contains **code only**. No personal data and no secrets are stored here.
Real settings are listed (without values) in `.env.example`.
